알고리즘 개요 및 핵심 개념

최단 경로 문제 (Shortest Path)

가중치가 있는 그래프에서 출발 정점부터 목적 정점까지, 간선 가중치 합이 최소가 되는 경로를 찾는 문제입니다.

경로의 비용 = 경로를 구성하는 모든 간선 가중치의 합

핵심 차이 한눈에

구분다익스트라플로이드-워셜
목적단일 출발점 → 모든 정점모든 정점 쌍
접근그리디 + 우선순위 큐동적 계획법
음수 간선불가가능*
시간O((V+E) log V)*O(V³)
공간O(V+E)O(V²)

* 다익스트라는 인접 리스트 + 이진 힙 기준. 플로이드-워셜은 음수 사이클이 없어야 최단 경로가 정의됩니다.

02 · Dijkstra

다익스트라 알고리즘

핵심 개념과 원리

  • 하나의 시작 정점에서 다른 모든 정점까지의 최단 거리를 계산합니다.
  • 현재까지 알려진 거리 중 가장 작은 정점을 먼저 확정합니다.
  • 확정한 정점을 거쳐 이웃 정점의 거리를 완화(relaxation)합니다.
전제: 모든 간선 가중치가 0 이상이어야 합니다.

주요 자료구조

  • 인접 리스트: 각 정점의 이웃과 간선 가중치 저장
  • PriorityQueue: 거리 기준 최소 힙
  • dist 배열: 시작점부터 각 정점까지의 현재 최솟값

04 · Dijkstra Code

다익스트라 핵심 구현 (Java)

import java.util.*; class Edge { int to, weight; Edge(int to, int weight) { this.to = to; this.weight = weight; } } static int[] dijkstra( List<Edge>[] graph, int start) { int n = graph.length; int[] dist = new int[n]; Arrays.fill(dist, Integer.MAX_VALUE); dist[start] = 0; PriorityQueue<int[]> pq = new PriorityQueue<>( (a, b) -> Integer.compare(a[1], b[1])); pq.offer(new int[]{start, 0}); while (!pq.isEmpty()) { int[] cur = pq.poll(); int u = cur[0], d = cur[1]; // 오래된 큐 항목은 무시 if (d != dist[u]) continue; for (Edge e : graph[u]) { if (dist[u] + e.weight < dist[e.to]) { dist[e.to] = dist[u] + e.weight; pq.offer(new int[]{e.to, dist[e.to]}); } } } return dist; }

구현 체크포인트

  • 우선순위 큐는 거리 오름차순으로 정렬
  • 거리 갱신 시 새 항목을 큐에 삽입
  • d != dist[u]로 오래된 항목 제거
  • 실제 서비스에서는 큰 가중치 합을 고려해 long 사용 권장

시간 복잡도

O((V+E) log V)

이진 힙 + 인접 리스트 기준. 단순 배열 구현은 O(V²).

JAVA · PRIORITYQUEUE05 / 12
05 · Dijkstra Caveats

다익스트라 주의점 및 특징

음수 간선이 불가능한 이유

다익스트라는 가장 가까운 정점을 꺼내면 그 거리가 최종 최단 거리라고 확정합니다.

하지만 음수 간선이 있으면 나중에 방문한 경로가 이미 확정된 정점의 거리를 더 작게 만들 수 있습니다.

예시: A→B(2), A→C(5), C→B(-10)
먼저 B를 2로 확정해도, C를 거쳐 B로 가면 -5가 됩니다.

특징 정리

  • 단일 시작점에서 모든 정점까지의 거리 계산
  • 음수 가중치가 없다면 효율적
  • 도달할 수 없는 정점의 거리는 ∞로 유지
  • 경로 자체가 필요하면 이전 정점을 저장하는 prev[] 배열 추가

06 · Floyd-Warshall

플로이드-워셜 알고리즘

핵심 개념과 원리

  • 모든 정점 쌍 (i, j)의 최단 거리를 한 번에 구합니다.
  • 동적 계획법(DP)을 이용해 경유 가능한 정점 집합을 점차 확장합니다.
  • k를 경유지로 허용했을 때 더 짧아지는지 모든 i, j 쌍을 확인합니다.
핵심 질문: i → j 직접 가는 것보다 i → k → j가 더 짧은가?

자료구조와 점화식

2차원 인접 행렬이자 DP 테이블 dist[V][V]를 사용합니다.

D[i][j] = min(D[i][j],
D[i][k] + D[k][j])

초기화: 대각선은 0, 무방향 간선은 양쪽에 같은 가중치, 나머지는 INF.

k가 가장 바깥 반복문이어야 DP의 의미가 유지됩니다.

음수 간선

허용 가능. 단, 음수 사이클이 없어야 최단 거리가 유한하게 정의됩니다.

시간 복잡도

O(V³)

정점 수가 작거나 모든 쌍 질의에 적합

공간 복잡도

O(V²)

거리 행렬을 저장

08 · Floyd-Warshall Code

플로이드-워셜 핵심 구현 (Java)

static final int INF = 1_000_000_000; static void floydWarshall(int[][] dist, int n) { for (int k = 0; k < n; k++) { for (int i = 0; i < n; i++) { for (int j = 0; j < n; j++) { // INF끼리 더하지 않도록 확인 if (dist[i][k] == INF || dist[k][j] == INF) { continue; } dist[i][j] = Math.min( dist[i][j], dist[i][k] + dist[k][j] ); } } } // 음수 사이클 확인 for (int i = 0; i < n; i++) { if (dist[i][i] < 0) { System.out.println("음수 사이클 존재"); } } }

무방향 그래프 초기화 예시

  • dist[i][i] = 0
  • 무방향 간선 (u, v, w): dist[u][v] = w
  • 반대 방향도 동일하게: dist[v][u] = w
  • 그 외는 INF

주의

INF를 더하면 정수 오버플로가 발생할 수 있으므로 도달 가능 여부를 먼저 확인합니다.

큰 가중치 범위에서는 long 타입을 고려하세요.

TRIPLE LOOP · DP TABLE09 / 12
09 · Floyd-Warshall Caveats

플로이드-워셜 주의점 및 특징

음수 사이클 감지

알고리즘 종료 후 어떤 정점 i에 대해 dist[i][i] < 0이면 음수 사이클이 존재합니다.

음수 사이클을 반복해서 돌면 경로 비용을 무한히 낮출 수 있어 해당 쌍의 최단 거리가 정의되지 않습니다.

음수 간선은 허용하지만, 음수 사이클은 별도로 감지해야 합니다.

특징과 사용 시 유의사항

  • 모든 출발점-도착점 쌍의 최단 거리 계산
  • 그래프가 조밀하거나 정점 수가 작을 때 구현이 간단
  • 정점 수가 커지면 O(V³) 연산량과 O(V²) 메모리가 부담
  • 경로 복원이 필요하면 next/parent 행렬을 추가로 갱신
정점 수 제한을 먼저 확인!
